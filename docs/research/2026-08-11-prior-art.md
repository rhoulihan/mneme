# Prior Art: Shared, Curated Agent Knowledge

**Date:** 2026-08-11 · **Purpose:** landscape survey informing the mneme design spec.
**Method:** four parallel research lanes — Claude Code ecosystem, memory infrastructure, commercial team-knowledge features, self-improving-agent patterns & knowledge commons.

## Executive summary

**The intersection mneme targets is empty as of August 2026.** Nobody ships: passive capture during normal agent work → local staging → user-curated review → PR into an open git knowledge repo → team inheritance via plugin updates. Every ecosystem has exactly one half:

- **Manual git-shared knowledge, no capture:** Cursor Rules, Copilot instructions, Amp skills, Factory AGENTS.md, Claude Code CLAUDE.md/plugins, every awesome-list commons.
- **Auto-capture into a proprietary store, weak or no review, no federation:** Devin Knowledge, Augment Cosmos, Windsurf Memories, Hivemind, Supermemory, mem0/Zep/Letta.

The "promotion gate + review queue" pattern mneme implements is documented in 2026 practitioner literature as a recommended best practice that teams must hand-build (MindStudio, Prismocode), and demanded verbatim in an open, unanswered Anthropic feature request (anthropics/claude-code#38536, filed 2026-03-25: team memory pools, personal→shared promotion, audit trails). Demand is proven; no product occupies the spot.

**Closest analogs, each missing mneme's core:**

| System | Has | Missing |
|---|---|---|
| **Claude Tag skills-repo** (Anthropic, Slack) | Agent opens PRs to org skills repo; human merges; auto-sync to all channels | Slack-only; skills-only (no facts); prompted, not passively captured; no local staging/curation layer |
| **Devin Knowledge** (Cognition) | Capture→suggest→edit→accept→org-wide loop; enterprise promotion; trigger-based recall | Proprietary cloud store — no git, no PR/diff/blame, one-click acceptance publishes org-wide, vendor lock-in |
| **claude-mem-sync** (lopadova) | Git-shared memories, optional PR gate, LLM distillation delivered as never-auto-merged PRs | Raw observation JSON, not curated skills/facts; requires claude-mem; per-project; no in-session curated share step |
| **Hivemind** (Activeloop) | Auto trace→SKILL.md at org/workspace scale, multi-agent | Zero human gating; proprietary Deep Lake backend; no PR provenance |
| **Letta Context Repositories** | Git-backed file memory: auto-commits, worktree isolation, merges | Single-agent-owner; git is plumbing, not collaboration; no human gate, no distribution |
| **Basic Memory Teams** | Markdown+frontmatter substrate, MCP, team workspaces | Instant ungated sharing; manual capture; own cloud, not customer git |
| **superpowers-skills** (obra) | Community fork-and-PR skills repo for Claude Code (737 stars) | **Archived within a month** — author: community sharing "requires more thought and design." Governance was the unsolved part |

## Lane 1 — Claude Code ecosystem

- **Native memory (Anthropic):** CLAUDE.md hierarchy (managed→user→project→local), modular `.claude/rules/*.md` with path-scoped `paths:` frontmatter, auto memory at `~/.claude/projects/<project>/memory/` (MEMORY.md index, 200-line/25KB load discipline, `modified` timestamps), `/memory`, `@imports`. Docs explicit: **"Auto memory is machine-local… not shared across machines."** Team channel = humans hand-editing git-tracked CLAUDE.md. https://code.claude.com/docs/en/memory
- **Plugin architecture:** `.claude-plugin/plugin.json`; `skills/`, `commands/`, `agents/`, `hooks/hooks.json`, `.mcp.json`, `monitors/`, `bin/`, plugin `settings.json`. Marketplaces: `marketplace.json` in any git repo, SHA/ref pinning, `/plugin marketplace update`; repo-level `extraKnownMarketplaces` in checked-in `.claude/settings.json` auto-offers plugins; claude.ai **Organization settings → Plugins** syncs private marketplaces via GitHub App (Team/Enterprise); managed settings force-enable. Distribution is a solved problem mneme rides for free. https://code.claude.com/docs/en/plugins · /plugin-marketplaces
- **Agent Skills standard (agentskills.io):** SKILL.md + YAML frontmatter (`name` ≤64 lowercase-hyphen matching dir, `description` ≤1024, `license`, `metadata` string-map for provenance), progressive disclosure, `skills-ref` validator. ~40 adopting products (Claude Code, Copilot, Cursor, Codex, Gemini CLI, Letta…). Spec deliberately omits versioning/registry — platforms own distribution. https://agentskills.io/specification
- **claude-mem (thedotmack):** dominant memory plugin (~46k stars); 5 lifecycle hooks, SQLite+FTS5+Chroma, session summaries. Cloud sync is single-user multi-device. Lesson: per-tool observation generation costs 60–90s latency. https://github.com/thedotmack/claude-mem
- **claude-session-memory (TeamSPWK):** hooks → auto-promoted typed "knowledge cards" (decision/constraint/gotcha/runbook/onboarding, YAML frontmatter) in-repo; secret scan pre-card. No review gate, per-repo, barely maintained. https://github.com/teamspwk/claude-session-memory
- **Self-learning harvesters:** Kulaxyz/self-learning-skills (~946 stars; promotion rule: verified success + named failure pattern + ≥1 eliminated dead-end; never persists secrets); UniM0cha/self-improving-skills (Stop-hook detached headless-claude distiller → `~/.claude/skills/`, `/curate-skills`, 30–90-day archival; explicitly individual-only). Capture→SKILL.md works; sharing is unserved. 
- **Demand:** anthropics/claude-code#38536 (open, unanswered). **Risk flag:** unverified blog claim of a leaked unshipped Anthropic "team memory sync engine" (server-synced KV, no curation) — even if real, not a governed knowledge repo.

## Lane 2 — Memory infrastructure

- **mem0** (63k stars): auto-extraction, 2026 single-pass ADD-only architecture, `org_id` scoping = namespace not workflow; admits "highly-retrieved memory becomes confidently wrong" (staleness) and an "unsolved identity problem" (attribution). https://mem0.ai/blog/state-of-ai-agent-memory-2026
- **Zep/Graphiti:** bi-temporal knowledge graph; contradictions **invalidate** edges (never delete) with validity windows — best-in-class automated contradiction handling, zero human loop. https://github.com/getzep/graphiti
- **Letta:** shared memory blocks across agents (instant propagation, last-write-wins hazards); **Context Repositories** (Feb 2026): git-backed memory FS, auto-commits, worktree-isolated memory subagents merging to main — closest mechanics, no human gate. https://www.letta.com/blog/context-repositories/
- **Basic Memory:** markdown notes = entities; `[category] fact #tag` observations; wikilink relations; SQLite index; Obsidian-compatible. Teams = instant shared cloud workspace, ungated. Nearest substrate neighbor. https://github.com/basicmachines-co/basic-memory
- **Cloudflare Agent Memory** (Apr 2026): two-pass extraction (broad+detail) → **eight-check verifier** before storage → typed memories (facts/events/instructions/tasks), topic-keyed **supersede-not-delete** → five retrieval channels fused with RRF. The industry's clearest automated quality gate; machine-only, per-agent, cloud-locked. https://developers.cloudflare.com/agent-memory/
- **Hindsight (Vectorize):** separates objective facts from subjective beliefs (four networks) — stealable epistemics. https://github.com/vectorize-io/hindsight
- **Git-native micro-projects:** DiffMem (markdown current-state + git history as temporal layer; retrieval = agent running grep/log/blame — **no vector infra needed**); GitAgent (agent-as-repo); Memoria (git-like diff-before-merge over a DB). All single-owner, no review layer. Git-Context-Controller paper: commit/branch/merge context management +13 points on SWE-Bench.
- Others surveyed: Cognee, LangMem, Supermemory (SMFS), Memobase, Hyperspell, Anthropic reference memory MCP server — all app-end-user personalization or single-agent continuity; none communal+gated.

## Lane 3 — Commercial team-knowledge features & governance

- **Cursor:** shipped auto-capture Memories (v1.0, Jun 2025), **removed the feature** (v2.1.x, Nov 2025) telling users to export to git-committed `.mdc` rules — market confirmation that reviewed files-in-git beat ambient memory stores. Team Rules pushed from dashboard (Team/Enterprise). No FedRAMP. https://cursor.com/docs/context/rules
- **Windsurf (Cognition):** auto Memories are local-only, non-shareable, legacy; docs steer teams to repo rules. **Governance bar for defense:** FedRAMP High, DoD IL4/IL5/IL6, ITAR via Palantir FedStart; Enterprise "System Rules" deployed read-only by IT. https://windsurf.com/blog/fedramp-certification
- **GitHub Copilot:** instructions files + org instructions + **Copilot Spaces** (curated context bundles, RBAC; legacy knowledge bases sunset Nov 2025). All hand-authored. Credibility-gap lesson: content exclusions "not supported in Edit and Agent modes." FedRAMP Moderate endpoints + data residency (Apr 2026). https://docs.github.com/en/copilot/concepts/context/content-exclusion
- **Devin Knowledge:** closest commercial loop (see summary table). Trigger descriptions per item, macros, repo pinning, folder hierarchy, org/enterprise scopes with promotion, per-user disable. Playbooks = versioned procedural units with revert. Acceptance is one user's click; store is proprietary. https://docs.devin.ai/product-guides/knowledge
- **Amp:** skills in `.agents/skills/` committed to repo, reads `.claude/skills/` for compatibility, `amp skill import/update` — most git-native distribution in market; no capture. https://ampcode.com/news/agent-skills
- **Augment Cosmos** (preview ~May 2026): "cross-agent organizational memory: a persistent, governed knowledge layer" — validates demand at platform level; auto-capture, no documented curation gate, closed store.
- **Factory.ai:** Knowledge droid indexes everything (RAG), curates nothing; ISO 42001 is a notable compliance differentiator.
- **Rules-file commons:** AGENTS.md — 60k+ repos, ~28 tools, Linux Foundation stewardship; awesome-cursorrules ~40k stars; github/awesome-copilot 31k stars/346 contributors; awesome-claude-code 20k+. **Communities already contribute agent knowledge via ordinary PRs — just hand-written.** https://agents.md/
- **Gov path:** Claude for Government Desktop (public beta 2026-07-07) brings Claude Code to agencies in a FedRAMP High environment with tamper-proof audit logs — a plugin rides an already-authorized platform. OMB M-25-21 requires agencies to apply risk-management practices to AI use; reviewable knowledge artifacts make an easier ATO story than ambient memory.

## Lane 4 — Self-improving agents & knowledge commons

- **Voyager** (2023): canonical skill-library loop; triple verification before commit (environment feedback, execution errors, self-verification critic); skills retrieved by embedded description; library transfers to new worlds; derivatives show a good library lets 8B models match GPT-4 results.
- **ACE** (Stanford/SambaNova 2025): Generator/Reflector/Curator separation; **context collapse** documented (18,282→122 tokens in one full-rewrite step; accuracy below no-memory baseline) and **brevity bias**. Fix: append-only, individually-addressable bullets with IDs + helpful/harmful counters; embedding dedup. **Never let an agent bulk-rewrite the store.** https://arxiv.org/abs/2510.04618
- **Agent Workflow Memory** (CMU): store abstracted workflows, only from evaluator-judged-successful trajectories; advantage grows with distribution shift.
- **Agent KB:** shared cross-agent experience KB; separate strategy-level vs execution-level knowledge retrieved at different moments (planning vs doing). +16 points GAIA. Ungoverned service. https://arxiv.org/abs/2507.06229
- **SkillWeaver/SkillOps:** practice-then-distill (skills tested before publication); APIs from strong agents boost weak agents up to +54% — knowledge from the best practitioners lifts everyone. SkillOps names **"skill technical debt"**: library-level rot needing health diagnostics, not just per-item review.
- **Dynamic Cheatsheet:** one transferable insight took GPT-4o from 10%→99% on Game-of-24 — the value density of a single good knowledge unit is enormous.
- **Karpathy's "system prompt learning"** (2025): the missing third paradigm — models editing their own instructions. Mneme = communal system prompt learning.
- **Claude Tag skills-repo** (Anthropic, 2026): shipped merge-gated agent-PR loop for Slack (see summary table). Includes a ready-to-steal **curation rubric**: API gotchas and reusable runbooks belong in the shared repo; one-off decisions and team-ownership facts stay in channel memory. https://claude.com/docs/claude-tag/admins/skills-repo
- **BerriAI/self-improving-agent:** cleanest confirm-gated agent-PR mechanics — schema gate `userConfirmedInThisMessage: true`, `onBeforeApply` validation, fine-grained PAT scoped to `contents:write`+`pull_requests:write` on one repo, draft PRs with rationale + risk assessment.
- **tldr-pages** (model commons pipeline): rigid unit template (≤8 examples), `tldr-lint` in CI settles format disputes by tooling, **two-maintainer approvals with time-decay fallbacks**, CLA, and an explicit anti-AI-slop policy (unreviewed generative-AI PRs closed). **awesome-list reciprocity gate:** review 4 open PRs before yours is considered — converts inbound demand into review supply. **Stack Overflow/Wikipedia:** trust tiers + review queues; pathology = reviewer burden.
- **Cautionary datapoint:** anthropics/skills — 167.8k stars, **762 open PRs vs 47 commits on main**. A commons without a review pipeline doesn't drown in noise — it silently stops absorbing anything.

## Design principles to adopt (cross-lane consensus)

1. **Verify before commit.** Machine gate first (extraction verifier, lint, secret scan), human gate second (harvest review, then PR review). Nothing enters the library just because it happened. (Voyager, AWM, SkillWeaver, Cloudflare, tldr)
2. **Small, schema'd, individually-addressable units; delta updates only.** Append and refine; forbid whole-store regeneration — that's how context collapse happens. (ACE)
3. **Supersede, never silently delete.** Git gives Graphiti's bi-temporality free: `git log` = validity windows, `git blame` = provenance, commits = authenticated authorship.
4. **Retrieval is a first-class surface.** The unit's `description` (trigger) deserves as much review as its body — description quality IS retrieval quality. (Voyager, Devin triggers, skill frontmatter)
5. **Separate roles: generate ≠ reflect ≠ curate.** The agent doing the work is not the pass that decides what's worth keeping. (ACE, Agent KB, retrospective patterns)
6. **Two knowledge tiers retrieved at different moments:** strategy/procedural (skills, consulted when planning/doing) vs declarative facts (rules/memory, loaded by scope). (Agent KB; matches the locked two-tier decision)
7. **Usage feedback closes the loop.** Track helpful/harmful signals per unit; selective pruning recovered ~10% absolute in the literature. Library health (dead links, stale deps) is a repo-level CI concern. (ACE, SkillOps)
8. **Topic-keyed dedup at stage time** so review shows "updates existing knowledge X" as a diff, not a duplicate. (Cloudflare, mem0)

## Failure modes mneme must design against

| Failure mode | Mitigation |
|---|---|
| Context collapse via bulk rewrite | Delta-only edits to ID'd units; agents may never regenerate whole files/stores |
| Error propagation (experience-following: bad merged item reproduces its error in every consumer) | Verify at capture; helpful/harmful counters; prune on harmful signals |
| Memory poisoning (MINJA >95% injection success ungated; OWASP agentic threat T1) | The human PR gate is the primary defense; plus CI content validation, per-contribution provenance/authn, snapshot/rollback (= git) |
| Staleness / "confidently wrong" knowledge | `last_verified` frontmatter; scheduled re-verification sweeps; staleness is worse in communal repos — errors propagate |
| Skill technical debt (library-level rot) | Repo CI health checks: link/dep checks, dead-skill detection, contract lint |
| **Review-throughput collapse** (the #1 commons killer) | Rigid schema + linter settles format by machine; batched curated shares (not PR firehose); small-N approvals with time-decay fallbacks; trust tiers; CODEOWNERS routing |
| Noise / brevity bias | Curation rubric (adapt Claude Tag's); Reflector distills concrete insights, never summaries; promotion rule: verified success + named failure pattern |
| Contradiction/duplication across contributors | Embedding/topic dedup at PR time; canonical-source rule per topic |
| Destructive concurrent writes | Git merge + PR review solves this class outright |

## Enterprise/government governance checklist

1. Human review gate before anything leaves the machine (staged candidates; explicit share step; no auto-push, ever).
2. PR-based approval with CODEOWNERS per knowledge area on the receiving repo.
3. Secret/PII/credential scanning pre-staging and pre-PR (gitleaks/trufflehog-class + PII detection); block-by-default with audited override.
4. Capture-exclusion config honored by the capture layer itself — path/repo/topic "never learn from this" (avoid Copilot's exclusions-don't-bind-agent-mode credibility gap).
5. Provenance metadata on every unit: who captured, source repo/session, when, who approved, version history (git + PR trail natively).
6. Tamper-evident audit trail of knowledge changes (git history + branch protection satisfies it if nothing bypasses them).
7. Classification/sensitivity labeling and distribution boundaries (CUI/ITAR-aware tagging for agencies).
8. No-cloud-dependency operation: everything local + customer-controlled git remote (GitHub Enterprise Server, GitLab self-hosted). Structural advantage over every SaaS competitor.
9. Admin-enforced baseline: org knowledge plugins users can't silently drop; admin kill-switch on capture.
10. OMB M-25-21 alignment: reviewable knowledge artifacts = easier ATO than ambient memory; rides Claude for Government Desktop (FedRAMP High) as a plugin.

## Formats & conventions to adopt

- **Procedural → spec-valid Agent Skills** (agentskills.io): `skills/<name>/SKILL.md`, trigger-rich `description`, `metadata` map for provenance (contributor, source session, review PR, version). Portability to ~40 tools.
- **Declarative → markdown fact files** with YAML frontmatter following native conventions: `.claude/rules/*.md`-style path scoping where relevant, index files under the 200-line/25KB discipline, `modified`/`last_verified` timestamps, ADR-lite typing (decision/constraint/gotcha/runbook), Basic-Memory-style `[category] fact #tag` observations where useful.
- **Packaging:** knowledge repos are themselves Claude Code plugins distributed via marketplace.json (version bumps on merge, SHA pinning), compatible with claude.ai org-sync and repo-level `extraKnownMarketplaces`.
- **Trust:** mirror the community-marketplace model — PR review + SHA pinning + CI validation (`claude plugin validate`, `skills-ref` lint) + safe-by-default share filters.
- **Reference implementation to emulate for repo quality:** obra/superpowers (per-skill tests, multi-harness packaging, version-bump automation).

## Strategic risks

1. **Anthropic generalizes Claude Tag's skills-repo loop to Claude Code.** Likeliest disruption; mneme's hedges: facts+skills (not skills-only), local staging/curation, multi-plugin registry+routing, open governance pipeline, cross-org federation, tool-agnostic format.
2. **Native team memory sync ships** (unverified leak): would be server-synced KV without curation — different layer; mneme should position as the governed tier above whatever ambient sync exists.
3. **Devin/Augment add git export + review gates.** Their stores and incentives are proprietary; open format + BYO-git is a structural moat, not a feature gap they can close quickly.
4. **Review-throughput collapse in real deployments** — the governance pipeline is the product; if reviewing knowledge PRs feels like a second job, adoption dies. Design the reviewer experience, not just the contributor experience.

## Answers to the plan's three key questions

1. **Does anything already do PR-gated communal agent memory?** No shipped system combines passive capture + local curated staging + PR-gated git commons + pull-based team inheritance. Claude Tag (Slack, skills-only, prompted) and Devin Knowledge (proprietary, one-click) are the near misses; superpowers-skills proved demand and archived on governance.
2. **Which formats won?** Markdown + YAML frontmatter in git, unanimously. Agent Skills spec for procedures (~40 tools); CLAUDE.md/AGENTS.md-family conventions for facts/rules; marketplace.json for distribution. Databases lost (Cursor killed Memories in favor of files-in-git).
3. **Failure modes and mitigations?** See tables above; the three that kill: context collapse (bulk rewrites), memory poisoning (ungated stores), review-throughput collapse (ungoverned commons). Mneme's architecture is the mitigation set.
